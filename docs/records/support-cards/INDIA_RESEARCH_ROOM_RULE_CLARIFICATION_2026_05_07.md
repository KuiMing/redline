# INDIA_RESEARCH_ROOM_RULE_CLARIFICATION_2026_05_07

日期：2026-05-07

## 使用者權威澄清
使用者已明確說明：

> 在所有奧援卡中，只能持有「印度奧援」，其他奧援卡都不能持有。

這條澄清高於先前的暫時推定。

## 規則收斂
因此 `印度研究分析室` 的最終實作方向應為：

### 允許
- 持有 `印度奧援`
- 購買 `印度奧援`
- 從棄牌堆 / 效果取得 `印度奧援`

### 禁止
- 持有任何其他奧援卡
- 購買任何其他奧援卡
- 從棄牌堆 / 效果取得任何其他奧援卡

### 不影響
- 一般 action cards
- 一般非奧援牌的購買 / 得牌 / 打出

## 已完成的 code 收斂
### server/game.py
- `_is_india_flag_card(card)` 已收斂成：
  - 只看 support taxonomy 的 `counts_as_flag_card`
  - 不再把 `transport / organization / spy / purge` 當成印度旗幟

### 驗證現況
- 非 support 一般牌：
  - 不會被錯算成印度旗幟
  - 仍可正常購買 / 得牌 / 打出
- `印度奧援`：
  - 可購買
- `英美奧援`：
