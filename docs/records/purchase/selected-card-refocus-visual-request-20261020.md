# 購買區已選卡重新聚焦視覺需求

記錄日期：2026-10-20
狀態：已完成（2026-10-20）

實作與驗證證據：`SELECTED_CARD_REFOCUS_VALIDATION.md`、`selected-card-refocus-20261020/`（桌面與客廳模式四種狀態截圖）。

## 使用者需求

購買區卡牌確定選擇後會顯示白色遮罩。當方向鍵再次聚焦該張卡牌時，該卡牌仍須顯示黃色邊框與中央準星。

## 視覺狀態

1. **已選且已聚焦**：同時顯示白色遮罩、黃色邊框與中央準星。
2. **已選但未聚焦**：只顯示白色遮罩。
3. **未選但已聚焦**：只顯示黃色邊框與中央準星。
4. **未選且未聚焦**：不顯示白色遮罩、黃色邊框或中央準星。

## 操作限制

- 方向鍵同一時間只可聚焦一張卡牌。
- 畫面最多只能有一組黃色邊框與中央準星。
- 白色遮罩代表已選狀態；黃色邊框與中央準星代表目前方向焦點。
- 已選狀態不得阻止焦點提示顯示。
- 規則適用於購買區內可由方向鍵聚焦的卡牌。

## 驗收證據

實作後需用正式 Browser UI 截圖及自動驗證確認四種視覺狀態，並確認方向輸入在已選卡牌上仍可顯示唯一焦點。
