# 陣營特殊能力事件追蹤稽核

日期：2026-08-16

## 稽核範圍

- 資料：`data/factions/all_faction.integrated.v2.json`
- 共用能力模板與文字解析：`server/game.py::_resolve_ability_ref()`、`_resolve_ability_text()`
- Runtime：所有主動、被動、出牌後、建立後、瓦解後、購買付款與回合結束能力
- 事件條件：`全國人大召開` 的 `use_faction_ability`
- 交易邊界：反應取消、待決選擇、非法目標、能力已不再生效的根據地

## 裁決

`全國人大召開` 的條件是「使用或觸發陣營特殊能力」。判定原則如下：

1. 主動能力在效果完成後計入。
2. 自動觸發能力在效果實際發生後計入。
3. 被動能力實際改變合法性、付款、移動或防禦結果時計入。
4. 設置能力只在遊戲建立時執行。當時尚未有進行中的事件，因此不計入事件進度。
5. `非暴力`、`新疆社會管控` 是陣營限制，不是玩家使用或觸發的正面能力，因此不計入。
6. 紅軍能力仍記錄為能力使用，但事件共用規則排除紅軍成為任務觸發者。
7. `共享組織` 是陣營間共用規則。軍火庫折扣是地圖城鎮效果。兩者都不是能力目錄中的陣營特殊能力，因此不計入。
