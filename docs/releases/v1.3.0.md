# REDLINE v1.3.0

v1.3.0 改善戰略地圖的路線辨識、操作順序與快速導覽。

## 新功能

- **快速返回根據地**：地圖右上角原有的「匯出畫面」控制改為「根據地」。按下後，地圖會讀取目前玩家的實際根據地並快速聚焦。

## 介面改善

- **相連路線提示**：選取任何城鎮後，相連道路會提高亮度與不透明度。路線寬度維持不變。
- **紅色虛線鐵路**：鐵路在一般、選取及縮放狀態下均使用紅色虛線。
- **精簡圖例**：圖例只保留金色一般道路與紅色虛線鐵路。
- **操作優先**：建立、移動及瓦解組織的操作區移至搜尋與聚焦控制之前。
- **移除重複標題**：移除地圖內重複顯示的「逆統戰」標題。

## 升級說明

1. 取得 `v1.3.0` source：

   ```bash
   git checkout v1.3.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   docker compose up --build -d
   ```

此版本沒有破壞性的相依套件或資料格式變更，也不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- MCP 的 Streamable HTTP 端點沒有內建身分驗證，設計上只給本機使用；若要對外開放，需要自行加上反向代理與驗證。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含正式容器替換、registry 發布或正式環境部署。
