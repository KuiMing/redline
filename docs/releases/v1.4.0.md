# REDLINE v1.4.0

v1.4.0 改善卡牌目標選擇、多人事件結算、取消反應及共用組織規則。

## 新功能

- **可取消主動瓦解選擇**：玩家主動使用瓦解組織的卡牌時，可在完成目標選擇前取消。取消不會消耗卡牌、行動、資源、組織、獎勵或事件進度。
- **保留強制事件規則**：事件要求的瓦解選擇仍不可取消。

## 規則與流程改善

- **「離間」多目標**：可選擇 1 至 3 位不同的其他玩家。透過「企業人脈」借用時也使用相同規則。
- **共用組織範圍**：一般行動、間諜行動、支援卡與時代條件會依各自規則判定共用組織的來源、擁有權與同意要求。
- **地圖目標篩選**：行動目標圈只顯示目前統治者／陣營篩選內的城鎮。
- **城鎮資訊**：控制者資訊會顯示玩家名稱與中文陣營名稱。共用組織保留黃色圓圈，但不再顯示額外的 `S` 標記。
- **精簡操作名稱**：建立與瓦解組織的地圖按鈕改用較短的名稱。

## 修正

- 修正多人事件與任務只對單一非紅軍玩家結算的問題。
- 修正「全國人大召開」未要求每位非紅軍玩家各自完成能力觸發的問題。
- 修正多人取消反應留下過期選項、重複接受舊選擇或在逾時後卡住遊戲的問題。
- 修正「盟旗學校」的棄牌成本未納入瓦解目標合法性，或多個目標的成本受資料順序影響的問題。
- 修正「北國奧援 III」未依實際剩餘合法目標結算的問題。
- 修正排隊卡牌可能遺留待處理選擇並阻塞遊戲的問題。

## 升級說明

1. 取得 `v1.4.0` source：

   ```bash
   git checkout v1.4.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   docker compose up --build -d
   ```

此版本沒有破壞性的相依套件或資料格式變更，也不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- MCP 的 Streamable HTTP 端點沒有內建身分驗證。此端點預設只供本機使用。若要對外開放，請自行加上反向代理與驗證。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含 image build、正式容器替換、registry 發布或正式環境部署。
