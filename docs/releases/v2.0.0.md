# REDLINE v2.0.0

REDLINE v2.0.0 新增完整 Joy-Con 桌面遊玩流程、重新設計的開局入口及遊戲選單，並改善回合操作、AI 紅軍公開資訊與玩家手冊。

## 主要更新

### Joy-Con 桌面遊玩

- 新增本機 Joy-Con Bridge。每位玩家可使用一支左或右 Joy-Con。
- 新增開局配對流程。玩家同時按 `SL + SR`，系統依配對順序建立本機席位。
- 新增完整 Joy-Con 導覽、卡牌操作、地圖聚焦、預覽、確認及取消操作。
- 遊戲畫面採固定 `1280 × 720` 舞台等比例縮放。非 16:9 畫面使用黑邊，不裁切或拉伸。

### 新的開始遊戲流程

- 首頁提供「真人紅軍」、「AI 紅軍」及「加入」三種入口。
- 房主可在同一畫面設定簡單／一般模式及電腦／Joy-Con 操作。
- 選擇 Joy-Con 時顯示電腦連線說明及配對狀態。
- 用房間代碼加入的玩家會沿用房主設定，不能修改房間模式。

### 遊戲選單與配樂

- 新增「遊戲選單」。滑鼠、鍵盤或目前操作席位的 Joy-Con 都可開啟。
- 遊戲選單包含返回遊戲、`Joy-Con 功能表`、配樂音量及重新開始。
- 重新開始使用第二層確認，避免誤離開目前遊戲。
- 新增本機同源循環配樂。音量範圍為 0%～100%，預設 30%，每次調整 10%。
- 勝利結算後可按 Y 重新查看勝利圖片。

### 回合與介面

- AI 紅軍回合會顯示公開行動報告，並在回合結束後等待玩家確認或逾時。
- Joy-Con 的 `SL` 可從任何遊戲分頁開啟全域地圖聚焦。
- 改善卡牌焦點、購買區、陣營能力面板及長手牌捲動行為。
- 移除「客廳大螢幕」顯示模式。產品統一使用桌面模式。

### 文件與部署

- 新增 Docker Compose 管理的 Joy-Con Bridge，並保留本機 loopback 限制。
- 更新 README、Joy-Con 控制文件及 `v2.0.0` 玩家手冊。
- 玩家手冊使用目前介面的真實 `1280 × 720` 截圖。

## 重要修正

- 修正多張同名手牌在狀態重繪後跳回前段卡牌的問題。
- 修正必選地圖目標停在其他分頁時，Joy-Con 無法繼續操作的問題。
- 修正全域地圖聚焦後，部分遠端目標使控制器失去地圖快照的問題。
- 修正 AI 紅軍公開行動與玩家動態重複顯示的問題。

## 升級說明

1. 取得 `v2.0.0` source：

   ```bash
   git checkout v2.0.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   docker compose up --build -d
   ```

4. 若要使用 Joy-Con，請確認 Docker Compose 的 Joy-Con Bridge 已啟動，並依畫面指示在電腦完成連線。

此版本沒有資料庫 migration。房間與進行中的遊戲不會跨服務重啟保留。

## 已知限制

- 瀏覽器可能阻止有聲 autoplay。此時配樂會等到可信任的滑鼠、鍵盤或觸控操作後開始。
- Joy-Con Bridge 只綁定本機。Joy-Con 必須連接執行瀏覽器的電腦。
- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- MCP 的 Streamable HTTP 端點沒有內建身分驗證。此端點預設只供本機使用。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含 image build、正式容器替換、registry 發布或正式環境部署。
