# REDLINE v1.0.0

v1.0.0 是 REDLINE 第一個可自行部署並在家中開桌遊玩的正式版本。

本版本以瀏覽器多人遊戲、主要原作玩法、陣營能力、卡牌流程、戰略地圖及勝利結算為正式支援範圍。

## 主要內容

- 支援 2 至 4 人多人作戰室、房主設定、準備狀態及 WebSocket 同步。
- 支援紅軍與多個反對陣營，以及陣營能力、根據地、時代關卡和專屬勝利條件。
- 支援行動卡、奧援卡、事件卡、常設購買區、隨機購買區及批次購買。
- 支援組織建立、移動、瓦解、共用組織、城鎮控制及地圖合法目標選擇。
- 支援陣營勝利、共同獲勝、紅軍生存勝利及勝利結算畫面。
- 提供 uv 與 Docker 的自行部署方式，以及玩家手冊與區網分享網址。

## v0.3.1 之後的變更

### 宛擴充地圖

- 新增 20 個宛擴充城鎮及其道路、鐵路、統治者與發展限制。
- 宛陣營現在可以在南陽及宛擴充地圖達成 14 個有效組織的勝利條件。
- 勝利條件文字明確列出完整的 21 個計分城鎮。
- 地圖會聚焦至宛擴充區域，並分開顯示位置相近的南陽與臥龍標記。

### 修正

- 修正延遲執行的亞洲地圖聚焦覆蓋已完成初始定位的問題。
- 修正 Lobby 建立 Game 時，陣營設定可能在兩個階段之間發生競態的問題。
- 修正一般指令牌或組織牌被取消後，系統未正確回報取消狀態的問題。

## 升級說明

1. 取得 v1.0.0 source：

   ```bash
   git checkout v1.0.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

此版本不需要資料庫 migration。重新啟動或替換服務前，必須先確認目前沒有需要保留的房間或對局。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- 部分事件與時代關卡效果仍可能與原作文字存在差異。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含正式容器替換、registry 發布或正式環境部署。
