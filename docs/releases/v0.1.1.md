# REDLINE v0.1.1

v0.1.1 是以玩家可見修正與可重現部署流程為主的小型維護版本。此版本修正臺灣時代效果期間與東洋奧援無合法目標時的提示，確認既有的拒絕出牌與卡牌保留行為不變，並修正兩個陣營能力名稱；同時加入 uv 專案 metadata 與 lockfile，讓本機及 Docker 建置使用一致的相依套件版本。

## 修正

- **臺灣時代效果維持完整整輪**：修正效果在錯誤回合邊界過早結束的問題，現在會持續到完整整輪結束。
- **東洋奧援無合法目標流程**：沒有合法目標時，改用正式 modal 告知玩家，並確認既有的拒絕出牌與卡牌保留行為不變。
- **陣營能力名稱**：`盟族學校` 更正為 `盟旗學校`；`選我河山` 更正為 `還我河山`。

## 開發與部署改善

- 新增 `pyproject.toml` 與 `uv.lock`，以 uv 管理並鎖定 Python 執行期與開發相依套件。
- 本機啟動方式改用 `uv run`。
- Docker image 建置改為先複製 `pyproject.toml` 與 `uv.lock`，再以 `uv sync --frozen --no-dev` 安裝鎖定的執行期相依套件。
- Docker 容器以 `uv run --no-dev uvicorn ...` 啟動，並維持單一 worker 的既有限制。

## 升級說明

1. 取得 v0.1.1 source（tag 發布後可 checkout `v0.1.1`）。
2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

若使用 Docker，請從 v0.1.1 source 重新 build image，再以單一容器／單一 worker 啟動。此版本不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態仍儲存在單一 Python process 的記憶體中；請勿使用多 worker 或多 replica，服務重啟時現有房間與對局不會保留。
- 本次驗證僅確認 release candidate 可成功 build 並通過 container smoke test；release 準備流程本身不包含 image 部署、registry 發布或正式環境驗證。
