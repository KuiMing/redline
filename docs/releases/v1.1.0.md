# REDLINE v1.1.0

v1.1.0 新增紅軍專用的非紅軍獲勝條件總覽。

## 新功能

- 紅軍玩家開啟「我的陣營」時，右側會顯示「非紅軍的獲勝條件」。
- 畫面列出目前遊戲中每位非紅軍玩家的名稱、陣營與公開獲勝條件。
- 非紅軍玩家仍顯示原本的時代關卡畫面。
- 新畫面不顯示其他玩家的手牌或私人狀態。

## 驗證摘要

本功能在合併前已完成聚焦驗證：

- 紅軍獲勝條件驗證：7/7 通過。
- 後端狀態投影 sanity check：10/10 通過。
- 實際 Browser 畫面確認紅軍可看到三位非紅軍玩家的獲勝條件，且非紅軍頁面維持原狀。
- 既有時代關卡驗證仍有一項事件面板遮擋問題；該問題在功能修改前已存在，未納入本版本修正。

依打版要求，本次 release preparation 沒有額外重跑產品測試。

## 升級說明

1. 取得 `v1.1.0` source：

   ```bash
   git checkout v1.1.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

此版本沒有相依套件或資料格式變更，也不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- 既有的事件面板遮擋驗證問題尚未修復。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含正式容器替換、registry 發布或正式環境部署。
