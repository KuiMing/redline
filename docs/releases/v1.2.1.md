# REDLINE v1.2.1

v1.2.1 改善遊戲結束後的重新開局流程，並修正「紅軍奧援」在資源模式下的棄牌去向。

## 新功能

- **勝利畫面可直接重新開始**：勝利結算畫面的「檢視最終盤面」旁新增「重新開始」。點擊後會離開已結束的對局，清除目前的房間與玩家識別，並回到乾淨的新遊戲大廳。

## 修正

- **「紅軍奧援」資源模式**：反共玩家將此牌作為資源時，現在會取得 1 資金與 1 宣傳、不抽牌，並將卡牌放入使用者自己的棄牌堆。卡牌依陣營轉移到其他玩家棄牌堆的規則只適用於打出行動。

## 驗證摘要

- 「紅軍奧援」修正：廣泛 pytest `1397 passed`；隔離 Browser proof `6/6 passed`；獨立審查結果為 `clean`。
- 勝利畫面「重新開始」：廣泛 pytest `1399 passed`；隔離 Browser proof `4/4 passed`；獨立審查結果為 `clean`。
- 兩項修正均已先合併到 `dev`，再透過 PR #147 整合到 `main`。

## 升級說明

1. 取得 `v1.2.1` source：

   ```bash
   git checkout v1.2.1
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   docker compose up --build -d
   ```

此版本沒有破壞性的相依套件或資料格式變更，也不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- MCP 的 Streamable HTTP 端點沒有內建身分驗證，設計上只給本機使用；若要對外開放，需要自行加上反向代理與驗證。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含正式容器替換、registry 發布或正式環境部署。
