# REDLINE v0.2.0

v0.2.0 加入新的 minimal vector basemap，降低底圖地名、POI、設施圖示及道路名稱對遊戲資訊的干擾，並提高暗色陸地、水域、海岸線、城鎮與遊戲路線的辨識度。此版本也修正香港「國際線」與「華文傳媒」的彈性付款規則，並補上程式碼與原作內容的授權範圍說明。

## 玩家可見變更

### Minimal vector basemap

- 底圖改用 OpenFreeMap vector style。
- 移除底圖原生地名、POI、商店、設施、交通圖示、道路名稱、次要道路與建築物。
- 保留暗色陸地、水域、海岸線、行政邊界及主要道路。
- Redline 的城鎮、道路、鐵路、組織、合法目標與地圖操作仍由既有 Leaflet overlay 提供。
- OpenFreeMap 載入失敗時會移除向量底圖，保留可操作的暗色遊戲盤面。

### 香港彈性付款

- 「國際線」與相同付款語意的「華文傳媒」會先使用玩家現有的宣傳。
- 資金只補足不足的宣傳費用。
- 例如 5 宣傳的「思想家」，玩家持有 3 資金與 2 宣傳時，會支付 **3 資金＋2 宣傳**。
- 批次購買共用同一份資源餘額，不會讓多張卡牌重複使用同一份宣傳。
- 資源不足時，整批購買會被拒絕，不會部分扣款或部分移動卡牌。

## 開發與部署變更

- 自託管 MapLibre GL JS `5.7.1` 與 MapLibre GL Leaflet `0.1.3`。
- 保留兩個上游套件的授權文字。
- 來源測試會驗證自託管執行資產的 SHA-256。
- 底圖載入流程涵蓋 style request failure、10 秒 timeout、plugin failure、必要 style layer 缺失、初始化錯誤及載入後 tile/runtime error。
- 新增 `LICENSE-CODE` 與 `LICENSE.md`，區分專案自行開發程式碼與《逆統戰》原作內容的權利範圍。

## 升級說明

1. 取得 v0.2.0 source：

   ```bash
   git checkout v0.2.0
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

若使用 Docker，請從 v0.2.0 source 重新 build image，再以單一容器及單一 worker 啟動。此版本不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態仍儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- OpenFreeMap 是公共服務，沒有正式 SLA。服務不可用時，系統會使用無外部底圖的暗色 fallback；Redline 遊戲 overlay 與操作仍會保留。
- 本次 release 流程不包含正式容器替換、registry 發布或正式環境驗證。
