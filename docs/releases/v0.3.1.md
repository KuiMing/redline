# REDLINE v0.3.1

v0.3.1 改善取消反應視窗。玩家現在可以直接確認即將被取消的行動、目標玩家及特殊能力效果，並使用更精簡、對齊一致的操作介面。

## 玩家可見變更

### 取消反應資訊

- 視窗會顯示「即將取消的行動」卡面預覽。
- 指定其他玩家的行動會顯示目標玩家名稱。
- 取消紅軍特殊能力時，卡面會顯示能力名稱、觸發時機及效果文字，不再使用空白或缺少內容的預覽。
- 問句整合至視窗標題，避免標題和說明區重複顯示相同內容。

### 取消操作

- 玩家只有一種取消牌時，視窗使用等寬的「是／否」按鈕。
- 玩家持有多種不同取消牌時，仍可選擇要使用的取消牌，或選擇不取消。
- 取消反應視窗改用精簡寬度。
- 卡面預覽置中顯示，不再因共用多欄選擇版面而偏移或被裁切。
- 操作按鈕維持一致寬度和間距。

## 開發變更

- 取消反應的玩家狀態投影新增 `target_player_id` 與 `target_player_name`，供反應玩家辨識原行動指定的玩家。
- 新增反應選擇投影測試，確認指定玩家資料正確，並維持取消牌只對反應玩家可見的既有隱私規則。

## 升級說明

1. 取得 v0.3.1 source：

   ```bash
   git checkout v0.3.1
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動正式服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

此版本不需要資料庫 migration。重新啟動或替換服務前，必須先確認目前沒有需要保留的房間或對局。

## 已知限制

- 房間與遊戲狀態仍儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- 本次 release 流程不包含正式容器替換、registry 發布或正式環境 cutover。
