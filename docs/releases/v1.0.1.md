# REDLINE v1.0.1

v1.0.1 是 `v1.0.0` 的玩家手冊修正版。

## 變更內容

- 依目前 `v1.0` 遊戲介面全面校正玩家手冊。
- 更新作戰準備室、陣營選擇、事件卡、行動、購買、戰略地圖、陣營能力及勝利結算說明。
- 重新拍攝 19 張 `1280×720` 實際遊戲截圖。
- 移除過時畫面，並讓每張截圖直接對應目前的操作控制項。

## 升級說明

1. 取得 `v1.0.1` source：

   ```bash
   git checkout v1.0.1
   ```

2. 使用 uv 依鎖檔同步環境：

   ```bash
   uv sync --frozen
   ```

3. 啟動服務：

   ```bash
   uv run uvicorn server.main:app --host 0.0.0.0 --port 8000
   ```

此版本沒有遊戲規則、產品程式碼、相依套件或資料格式變更，也不需要資料庫 migration。

## 已知限制

- 房間與遊戲狀態儲存在單一 Python process 的記憶體中。服務重啟時，現有房間與對局不會保留。
- 請勿使用多 worker 或多 replica。
- 本專案是非官方二次創作。原作內容僅限非商用並須註明出處。
- 本次打版不包含正式容器替換、registry 發布或正式環境部署。
