# 逆統戰・玩家手冊

這份手冊帶你走過一局遊戲的完整流程：從建立房間、選陣營，到出牌、購買、建立組織、
使用陣營能力，一直到遊戲結束。畫面全部是真的遊戲截圖，不是示意圖。

規則的完整細節（各陣營勝利條件、卡牌效果原文等）請參考 `rules.md`；這份手冊只講
「畫面上要點哪裡、順序是什麼」。

---

## 1. 開始一局遊戲

### 1.1 建立或加入房間

打開網址後會看到「作戰準備室」。輸入你的玩家名稱，按「**建立作戰室**」開一個新房間，
或是把別人分享給你的房間代碼貼進「建立／加入房間代碼」欄位，按「**進入作戰室**」加入。

建房的人畫面上會多一欄「**區網連線網址（給其他玩家）**」——把這個網址分享給同一個
Wi-Fi／區網下的其他玩家，他們打開瀏覽器貼上這個網址、再貼上房間代碼，就能加入。

![首頁／作戰準備室](player-guide/screenshots/01_home_lobby_screen.png)

### 1.2 選擇陣營

建房後畫面會多出「陣營選擇」區塊，列出所有可選陣營的大分類。

![陣營分類清單](player-guide/screenshots/02_faction_picker_categories.png)

點選一個陣營大類後，如果該陣營底下還有不同的根據地／路線可選（例如臺灣分「綠線」
「藍線」），畫面會再列出子選項；選定後按「**確認陣營**」。同一個陣營／根據地在同一
局裡只能被一位玩家選走。

![確認陣營與根據地](player-guide/screenshots/03_faction_picker_confirm.png)

### 1.3 等待其他玩家、準備、開始

右側「PLAYER ROSTER」會即時顯示每位玩家目前選了什麼陣營、是否已準備。

![房間名單](player-guide/screenshots/04_lobby_room_roster.png)

所有人都選好陣營、按下「**我已準備**」之後，房主的「**啟動行動**」按鈕才會亮起，
按下去就正式開局。

![全員準備完成](player-guide/screenshots/05_lobby_ready_to_start.png)

## 2. 遊戲畫面總覽

開局後預設停在「**指揮中心**」頁籤，這是你大部分時間會用到的畫面：

![指揮中心總覽](player-guide/screenshots/06_command_center_overview.png)

- **上方 HUD**：目前回合數、階段（行動階段）、當前輪到誰、你的手牌數／資金／
  宣傳／移動點、以及每位玩家目前的組織總數。
- **右上角事件卡**：本回合翻出的事件卡，點一下可以放大看任務條件、成功獎勵、
  失敗懲罰。

  ![事件卡放大檢視](player-guide/screenshots/07_event_card_zoom.png)

- **中間分頁列**：指揮中心／戰略地圖／戰況紀錄／我的陣營，四個畫面之間切換。
- **常設購買區／隨機購買區**：可以花資金／宣傳購買的卡牌。
- **手牌區**：你目前手上的牌，每張牌下面有「資源」「行動」兩個按鈕。

## 3. 行動階段：出牌與購買可以自由交錯

輪到你的時候，畫面上方會出現「**行動階段｜下一步：結束行動階段**」的提示。這個階段
裡，**出牌、購買、使用陣營能力可以任意順序、重複交錯進行，沒有先後限制**，一路做到
你覺得可以收尾了，再按「結束行動階段」一次即可——不需要先買完才能出牌、也不需要
先出完牌才能買。

### 3.1 出牌：資源模式 vs 行動模式

每張手牌下方都有兩個按鈕：

- **資源**：把這張牌當資源用，換取上面標示的資金／宣傳。
- **行動**：打出這張牌的行動效果（如果有的話；有些卡的行動模式沒有額外效果）。

按「資源」出牌後，資金／宣傳會立即增加：

![打出手牌換取資源](player-guide/screenshots/08_play_card_resource_mode.png)

### 3.2 購買卡牌

購買區的每張卡左上角都有勾選框，勾選想買的卡（可以一次勾多張），畫面會顯示
「已選 N 張｜合計 X 資源」，按「**購買所選 N 張**」。

![勾選要購買的卡牌](player-guide/screenshots/09_purchase_area_select.png)

會跳出確認視窗，再次確認要花費的資源與卡牌內容：

![購買確認視窗](player-guide/screenshots/09b_purchase_confirm_modal.png)

買到的卡會直接進棄牌堆，**不會立刻加入手牌**，要等下次補牌／重新洗牌抽到才會用到。

購買完成後，注意常設購買區的「剩 N」數字會減少，而且——**你仍然可以繼續打出手上
剩下的牌**，不需要先結束行動階段：

![購買後仍可繼續出牌](player-guide/screenshots/10_play_card_after_purchase.png)

### 3.3 在戰略地圖上建立組織

切到「**戰略地圖**」頁籤可以看到整張地圖、每個城鎮目前的組織歸屬。你自己陣營的
根據地會用一個帶陣營代表色外框的圓圈＋帳篷圖示標示出來。

![戰略地圖總覽](player-guide/screenshots/11_strategic_map_overview.png)

打出**帶有「建立組織」效果的行動卡**（例如宣傳家）之後，畫面會自動幫你標示出所有
合法可以建立組織的候選城鎮：

![建立組織：地圖上標示候選城鎮](player-guide/screenshots/12_build_organization_map_prompt.png)

點選其中一個城鎮，左側面板會顯示「在目前城鎮建立組織」按鈕（可用時會亮起）：

![選定城鎮、按鈕轉為可點擊](player-guide/screenshots/13_build_organization_confirm_button.png)

按下去就完成建立，該城鎮會多出你的組織棋，你的組織總數（HUD 上「組織 N」）也會
增加：

![組織建立完成](player-guide/screenshots/14_build_organization_done.png)

### 3.4 結束行動階段

覺得這回合該做的都做完了，按「**結束行動階段**」——系統會自動幫你把手牌補到 5 張、
補滿購買區，然後換下一位玩家：

![結束行動階段、手牌補到 5 張、換人](player-guide/screenshots/15_end_action_phase_hand_refilled.png)

## 4. 陣營能力

有些陣營（例如紅軍）有專屬的主動能力，畫面上會多一顆「**OO能力**」按鈕，同樣可以
在行動階段裡任何時候按，不影響出牌／購買。按下去會列出這個陣營所有能力選項與簡短
說明：

![紅軍能力選單](player-guide/screenshots/16_red_army_ability_modal.png)

想查自己陣營完整的能力說明、根據地、規則與限制，切到「**我的陣營**」頁籤：

![我的陣營頁籤](player-guide/screenshots/17_my_faction_panel.png)

---

## 5. 遊戲怎麼結束

遊戲會在有玩家達成自己陣營的勝利條件時結束（各陣營勝利條件不同，詳見「我的陣營」
頁籤或 `rules.md`）；如果到第 20 回合結束都沒有人達成，紅軍保底獲勝。

結束畫面會顯示獲勝者、簡短的劇情收尾文字，以及每位玩家最終的組織／牆內／牆外／
資金／宣傳數據：

![遊戲結束畫面](player-guide/screenshots/18_victory_screen.png)

## 6. 快速提示

- **卡牌模式**：建房時可以選「53 張核心」或「全部卡牌」，決定這局要用精簡版還是
  完整版的卡池。
- **移動**：在戰略地圖上點選自己有組織的城鎮，再點目的地，會出現移動確認；每次
  移動消耗手上的「移動」點數（由部分卡牌效果提供）。
- **瓦解**：只有少數卡牌／事件／能力能夠瓦解其他玩家的組織，觸發時地圖會自動用
  💀 標示出合法目標，點選後在左側按鈕確認即可，不會誤觸。
- **戰況紀錄**：想回顧「剛剛發生了什麼」，切到「戰況紀錄」頁籤看逐行的行動紀錄。
